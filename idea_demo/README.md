# AutoPM Demo Website

🚀 **AI-Powered Project Management Assistant Demo**

A modern, dark-themed demo website showcasing AutoPM - The AI Copilot for Automotive Project Management.

## ✨ Features

- 🌓 **Dark/Light Theme Toggle** - Seamless theme switching with localStorage persistence
- 🎨 **Modern Dark Theme** - Stunning gradients, glassmorphism effects, and smooth animations
- 📱 **Fully Responsive** - Optimized for all screen sizes
- ⚡ **Framer Motion Animations** - Professional animations throughout the site
- 🎯 **Interactive Dashboard** - Live demo of AutoPM's capabilities with tabbed interface
- 🔥 **Great Visuals** - Eye-catching hero section, floating cards, and animated elements

## 🎯 Sections

1. **Hero Section** - Eye-catching introduction with gradient text and floating cards
2. **Features** - 8 unique features with hover effects and icons
3. **Interactive Dashboard** - Live demo with Overview, Risks, and Workload tabs
4. **Tech Stack** - Technologies used with interactive tags
5. **Team** - Team Porotta Pythoners information
6. **Footer** - Complete footer with links and social media

## 🚀 Quick Start

### Install Dependencies
```bash
npm install --legacy-peer-deps
```

### Run Development Server
```bash
npm run dev
```

The app will be available at `http://localhost:5173/`

### Build for Production
```bash
npm run build
```

### Preview Production Build
```bash
npm run preview
```
